# 版本日志 - v1.2.0 (2026-08-05 19:00:00)

## 变更说明

1. **移除强制 Key 格式正则与必填邮箱限制**:
   - 之前源码强制校验 Cloudflare Key 为 37 位 16 进制 Global Key，并要求必须填写 Email。
   - 现已重构鉴权逻辑，同时支持 **Cloudflare API Token** (邮箱可留空，使用 `Bearer <token>` 鉴权) 和 **Global API Key** (`X-Auth-Email` + `X-Auth-Key` 鉴权)。

2. **多语言 (中英文) 切换**:
   - 在页面右上角铺开展示中英文切换按钮 `[ 简体中文 ]` 和 `[ English ]`。
   - 一键无刷新实时切换全局 UI 文本、表单提示与日志说明。

3. **单版面 (Single Screen) 无滚动条视觉优化**:
   - 优化响应式 CSS 网格与排版，确保在桌面端和移动端都在一个版面内完整呈现，避免出现冗余滚动条。

4. **主界面「AI API 设置」功能**:
   - 支持本地存储 (`localStorage`) 保存配置。
   - 可在默认 Gemini API (系统 Key) 和自定义 OpenAI 兼容接口 (Base URL / API Key / Model) 之间灵活切换。
   - 附带「免费 AI API 获取指南」弹窗，提供详细获取渠道、优缺点对比及配置示例。

5. **代码解耦与文件拆分 (< 600 行)**:
   - 拆分原 `server.mjs` (原本 700 行) 为模块化的 `lib/cf-api.js` 和 `lib/deploy-engine.js`，保证任何单一文件代码不超过 600 行。
   - 优化 `functions/api/[[path]].js` 边缘函数模块，确保严格满足代码规范。

6. **规范标题命名**:
   - 应用标题与浏览器 Title 统一加 `iBanKa！` 前缀（`iBanKa！云端部署器`）。
